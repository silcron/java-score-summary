# 성적 요약

여러 점수를 입력하면 평균, 최고점, 최저점, 합격 인원을 계산하는 Java 프로그램입니다.

## 실행 방법

JDK가 설치된 환경에서 아래 명령어로 실행합니다.

```sh
javac -encoding UTF-8 ScoreSummary.java
java ScoreSummary 85 90 55
```

실행 결과:

```text
Count: 3
Average: 76.67
Highest: 90
Lowest: 55
Passed (60+): 2
```

## 입력 기준

- 점수는 공백으로 구분해서 입력합니다.
- 0~100 사이의 정수만 입력할 수 있습니다.
- 60점 이상을 합격으로 계산합니다.
- 점수가 없거나 입력이 잘못되면 사용 방법 또는 오류 메시지를 출력합니다.

## 코드에서 사용한 내용

입력받은 점수를 배열에 담고, 반복문으로 합계와 합격 인원을 계산합니다. 평균을 구할 때는 실수로 변환하고 소수점 둘째 자리까지 출력합니다.
